# Projeto P2 

Aplicativo de delivery desenvolvido em React Native com Expo Router e TypeScript para a avaliação da P2. O projeto conta com mais de 12 telas funcionais, navegação por abas com contador dinâmico, consumo de API externa (ViaCEP) e persistência de dados local (`AsyncStorage`).

## Tecnologias Utilizadas
- **React Native / Expo & Expo Router** 
- **TypeScript** 
- **AsyncStorage** 
- **Fetch API** 
- **Vector Icons** 

## 📱 Telas Desenvolvidas (13+ telas)
1. **Início / Boas-vindas** 
2. **Login** 
3. **Cadastro com AsyncStorage** 
4. **Home / Restaurantes** 
5. **Busca com Filtros e Categorias** 
6. **Cardápio / Detalhes do Produto** 
7. **Sacola / Carrinho** 
8. **Pagamento e Cupons**
9. **Cupons de Desconto** 
10. **Status do Pedido em Tempo Real** 
11. **Histórico de Pedidos** 
12. **Endereços com Consulta ViaCEP** 
13. **Central de Ajuda (FAQ)** 
14. **Perfil do Usuário**
